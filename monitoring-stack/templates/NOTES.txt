  └─────────────────────────────────────────────────────────────────────────┘

  Four dashboards are provisioned automatically (no import needed):

    Cluster Health     nodes ready, pods by phase, capacity, firing alerts
    Nodes              per-node CPU / memory / disk / network
    Pods & Workloads   per-pod CPU / memory / restarts, top consumers
    Logs               live pod logs from Loki, filterable by namespace and pod

  It takes 2-3 minutes after install before panels fill in — Prometheus has to
  scrape, then remote_write into VictoriaMetrics.

  ┌─ CHECK IT IS WORKING ───────────────────────────────────────────────────┐

    kubectl get pods -n {{ .Release.Namespace }}
    kubectl get pvc  -n {{ .Release.Namespace }}

    # both DaemonSets should read 2/2 — that is what proves the tainted
    # control-plane node is being monitored too
    kubectl get ds -n {{ .Release.Namespace }}
  └─────────────────────────────────────────────────────────────────────────┘

  ┌─ REMOVE EVERYTHING ─────────────────────────────────────────────────────┐

    helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
    kubectl delete ns {{ .Release.Namespace }}

    Both commands are needed: Helm does not delete the PVC that
    VictoriaMetrics' StatefulSet created, so the namespace delete is what
    reclaims the disk. `make uninstall` runs both for you.
